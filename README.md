
# Controle Financeiro em Python

Projeto desenvolvido em Python para praticar organização de código, modularização e gerenciamento de transações financeiras.

## Funcionalidades

- Cadastro de categorias financeiras
- Registro de receitas e despesas
- Associação de transações a categorias
- Cálculo do saldo total

## Tecnologias

- Python 3
- Git e GitHub
- Visual Studio Code

## Estrutura do projeto

- `main.py` — execução principal
- `categoria.py` — categorias financeiras
- `transacao.py` — transações financeiras
- `utilitarios.py` — funções auxiliares
- `TODO.md` — planejamento e melhorias

## Como executar

1. Instale o Python 3.
2. Clone este repositório.
3. Abra a pasta do projeto.
4. Execute no terminal:

```bash
python main.py
```

## Objetivo

Desenvolver habilidades em programação Python, funções, modularização e organização de projetos, aplicando conceitos de desenvolvimento de software.
